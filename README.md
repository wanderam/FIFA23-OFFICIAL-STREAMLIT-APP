# Dados FIFA23 para App Streamlit

Aplicativo Streamlit desenvolvido para mostrar dados sobre jogadores de futebol de 2017 a 2023 fornece informações abrangentes sobre jogadores profissionais de futebol. O conjunto de dados contém uma ampla gama de atributos, incluindo dados demográficos dos jogadores, características físicas, estatísticas de jogo, detalhes de contratos e afiliações a clubes.

Acesse o aplicativo [aqui](https://fifa23-official-app-app-farjnggglwjvbvgio5zvbd.streamlit.app/).
